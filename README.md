# English Club

Página web para practicar inglés en casa con niños de 2° de básica (nivel Pre-A1), en dos sesiones de fin de semana.

- **Tarjetas** con dibujo y audio en inglés (voz del dispositivo), también en modo lento por sílabas.
- **Juegos**: He / She / It / I / You, "Is it…?", clasificar (seres vivos, animales, materiales) y armar palabras.
- **Mini show**: guiones cortos para practicar exposiciones orales.
- **Mis estrellas**: checklist semanal.

Es un solo archivo (`index.html`), sin dependencias ni servidor. El progreso se guarda en el navegador (localStorage).
